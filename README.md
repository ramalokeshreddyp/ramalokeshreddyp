## Selected Work

### Code to Win

A full-stack competitive programming analytics platform built with React, Node.js, Express, MySQL, and JWT authentication.

- Solves a real problem for developers who needed one place to track coding progress across platforms.
- Uses automated cron jobs and web scraping pipelines to keep performance data updated.
- Reached 5,000 active users.
- If usage grows from 5,000 to 5 million, the path is clear: cache aggressively, move scraping to queues, batch writes, add pagination and rate limits, and split read-heavy analytics from write-heavy ingestion.

### BoardPulse

A production-ready real-time collaborative Kanban board built with Django Channels, Redis pub/sub, PostgreSQL, and Docker Compose.

- Every task move is broadcast instantly to connected users.
- Secure WebSocket authentication rejects unauthenticated connections at the protocol level.
- Benchmark: P95 WebSocket latency of 9.14ms across 10 concurrent clients.
- The architecture is built to scale horizontally with more consumers, shared Redis state, and separated real-time fanout from persistent storage.

### FatePick

A clean and fast React 18 + TypeScript application built with Tailwind CSS.

- Uses the Fisher-Yates algorithm for fair randomization.
- Supports bulk CSV import and client-side PDF/XLSX export.
- Deployed on Vercel.
- Keeps the experience light by doing as much work as possible on the client, reducing server load and keeping response times predictable.
